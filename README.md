# 🛠️ PowerShell Playground

This repository is my personal PowerShell learning space.

I use it to collect useful PowerShell commands, notes, examples and small experiments that help me understand how things work in practice.

I already use PowerShell in my IT work, mostly through ready-made scripts and practical commands. This repository is where I slow down, write things out and build a better understanding of the logic behind the commands.

My learning is based on Microsoft Learn documentation, especially Microsoft Graph PowerShell documentation such as:

https://learn.microsoft.com/en-us/powershell/module/microsoft.graph.users/get-mguser?view=graph-powershell-1.0

I also use my own notes from real work situations, commands I have used and things I have needed to troubleshoot or understand better.

The goal is simple:

- collect useful commands
- document what they do
- understand how PowerShell handles objects and pipeline output
- keep notes for future reference
- practise writing clearer and safer scripts over time

This is not meant to be a perfect script library.

It is a growing notebook for PowerShell learning, troubleshooting and practical IT work.

PowerShell is an excellent tool, especially in IT administration, Microsoft 365 and identity-related work. But it is also important to remember that PowerShell can cause real damage if you do not understand what you are doing, what command you are running or what object you are changing.

That is one reason why this repository exists.

I want to understand the commands, not just copy and run them.

My basic rule is:

> Read first. Understand second. Change last.

This repository is part of that learning process.
