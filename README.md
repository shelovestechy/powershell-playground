# 🛠️ PowerShell Playground

This repository is my personal PowerShell learning space.

I use it to collect useful PowerShell commands, notes, examples and small experiments that help me understand how things work in practice.

I already use PowerShell in my IT work, mostly through ready-made scripts and practical commands. This repository is where I slow down, write things out and build a better understanding of the logic behind the commands.

The goal is simple:

- collect useful commands
- document what they do
- understand how PowerShell handles objects and pipeline output
- keep notes for future reference
- practise writing clearer and safer scripts over time

This is not meant to be a perfect script library.

It is a growing notebook for PowerShell learning, troubleshooting and practical IT work.
