# Source policy

Every exercise should link to a reliable source when one is available.

## Preferred source order

1. Official Microsoft Learn documentation for PowerShell, Microsoft Graph, Entra ID, Exchange Online and Windows
2. Official GitHub documentation for Git and GitHub workflows
3. Original standards and legislation such as NIST, ISO or EUR-Lex
4. Vendor documentation for a vendor-specific tool
5. Community sources only when the official documentation doesn't answer the question

## What an exercise should include

- the exact cmdlet documentation
- authentication or connection documentation when needed
- required scopes or roles
- a note when the command hasn't been tested in a live environment
- the date or context when version differences matter

A source confirms what a command is designed to do. It doesn't prove that the command is approved for every workplace or tenant.
