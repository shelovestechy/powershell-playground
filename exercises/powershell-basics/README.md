# PowerShell basics

This track is for the small things that make every later script easier to understand.

## Planned topics

- commands and help
- variables and data types
- objects and properties
- filtering with `Where-Object`
- selecting output with `Select-Object`
- loops and pipelines
- functions and parameters
- errors and `try` / `catch`
- paths, files and folders

These exercises will stay small. Nobody needs a twelve-file architecture to learn what `Get-Member` does.
