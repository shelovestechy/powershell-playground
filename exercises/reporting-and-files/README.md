# Reporting and files

Exercises for turning PowerShell objects into output that another person can review.

## Planned topics

- create an Excel-friendly CSV
- import a review list
- compare two lists
- find duplicates
- add a report date and source
- protect output containing work data
- create a small HTML report

A pretty spreadsheet can still contain the wrong answer. The exercises will keep the source and limitations visible.
