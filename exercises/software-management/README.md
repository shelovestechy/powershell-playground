# Software management

Exercises for installed applications, uninstall information and common software problems on Windows.

## Planned topics

- list installed desktop applications
- find an application's uninstall command
- inspect MSI product information safely
- identify Microsoft Store applications
- check whether an application is still running
- investigate a broken uninstall entry
- use `-WhatIf` before a supported change
- document manual cleanup without turning it into a universal removal script

The track will begin with read-only discovery. Actual removal commands will be red exercises and will include a warning, test plan and recovery notes.
